# NixOS Dotfiles

Dotfiles for hyprland, hyprlock, alacritty, and neovim.

### Install

```sh
stow -t ~/ hypr
stow -t ~/ nvim
stow -t ~/ kitty
stow -t ~/ waybar
stow -t ~/ ticker
stow -t ~/ qutebrowser
stow -t ~/ rmpc
stow -t ~/ bin
stow -t ~/ swayimg
stow -t ~/ walker
stow -t ~/ rofi
stow -t ~/ btop
stow -t ~/ dunst
```
